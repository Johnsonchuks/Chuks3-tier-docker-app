# 3-Tier Dockerized Application on Azure

This project demonstrates a full-stack architecture containerized with **Docker** and deployed on a **Microsoft Azure** Virtual Machine. It features a React-based frontend, a Node.js backend, and persistent data management.

## 🚀 Live Demo
The application is accessible at: [http://20.124.205.26](http://20.124.205.26)

## 🏗️ Architecture
The system follows a standard 3-tier architecture:
1.  **Presentation Tier:** React/Nginx (Frontend)
2.  **Logic Tier:** Node.js/Express (Backend API)
3.  **Data Tier:** MongoDB/Database



## 🛠️ Tech Stack
* **Cloud:** Microsoft Azure (Ubuntu 24.04 LTS)
* **Containerization:** Docker & Docker Compose
* **Web Server:** Nginx
* **Runtime:** Node.js
* **Registry:** Docker Hub
